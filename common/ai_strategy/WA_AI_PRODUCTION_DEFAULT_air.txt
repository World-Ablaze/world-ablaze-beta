# ============================================================================
# [air-budget] Air production lines, DEFAULT tier. One block per LINE, enabled by the layer-3
# decision WA_AI_PRODUCTION_should_open_<line>_line (WA_AI_PRODUCTION_air.txt) that the purge
# pulse reads too; a CANCEL block is its complement (-1000 on an archetype no open line funds).
# The LAND pool's unit_ratio is NOT here: WA_AI_AIR_BUDGET_reconcile emits it monthly from the
# open types (WA_AI_PRODUCTION_air_budget.txt). The category factor is ONE block per TYPE (end of
# file), never per line - factors of one id SUM across enabled blocks, so three open tactical
# lines would push that category three times; every funded archetype factor is at parity (100):
# a second lever per type re-deforms the share the weights just fixed. The carrier pool's
# unit_ratio is emitted by the same reconcile from the carrier type gates.
# `ai_strategy value =` is a literal - `constant:` is not resolved here (wa-constants-registry).
# ============================================================================

# A land fighter archetype no fighter line funds is denied outright: the old pulse re-purged both

# the cancel-per-pulse. Assumes the trio above is the only funding of these two archetypes.
