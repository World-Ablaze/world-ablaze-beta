# ============================================================================
# [air-budget] Air production lines, DEFAULT tier. One block per LINE, enabled by the layer-3
# decision WA_AI_PRODUCTION_should_keep_<line>_line (WA_AI_PRODUCTION_air.txt) = that line is
# open OR maintained; a CANCEL block is its complement (-1000 on an archetype no kept line funds).
# [air-budget] `keep`, not `open`, on purpose: a line whose park reached its cap keeps its
# archetype factor and its floor so the park still modernises. What retires at the cap is the
# unit_ratio weight and the category factor, both read from should_fund_<type>_type, which stays
# the open-only gate. The maintenance FLOORS are the last section of this file.
# The LAND pool's unit_ratio is NOT here: WA_AI_AIR_BUDGET_reconcile emits it monthly from the
# open types (WA_AI_PRODUCTION_air_budget.txt). The category factor is ONE block per TYPE (end of
# file), never per line - factors of one id SUM across enabled blocks, so three open tactical
# lines would push that category three times; every funded archetype factor is at parity (100):
# a second lever per type re-deforms the share the weights just fixed. The carrier pool's
# unit_ratio is emitted by the same reconcile from the carrier type gates.
# `ai_strategy value =` is a literal - `constant:` is not resolved here (wa-constants-registry).
# ============================================================================

########################## maintenance floors, one pair per TYPE ##########################

# [air-budget] The factory floor a role keeps while its park sits at its cap. Without it the
# type's weight and category factor are gone, the engine allocates zero factories, and a mature
# park flies the airframe it had for the rest of the campaign - a stock full of obsolete planes
# and nothing replacing them. Two blocks per role, ADDITIVE with each other and with the
# `min_factories 1` its line block already carries (MEASURED additive on the carrier floors,
# WA_AI_PRODUCTION_carrier_planes.txt): 2 factories for a wartime industry, 5 above the large
# band. Gated on WA_AI_PRODUCTION_should_maintain_<type>_type, which is false whenever any line of
# that role is OPEN - a role being funded normally never reaches these blocks.
#
# Two known deviations from the 2 / 5 pair, both deliberate:
#   - tactical_bomber: fast, strike and tactical are non-exclusive when open, so a country running
#     all three archetypes carries all three line floors and lands above 5. Three airframes to
#     modernise, three floors.
#   - fighter with the interceptor line alone maintained: the interceptor block carries no
#     min_factories of its own (it never did), so that country floors at 1 / 4 instead of 2 / 5.
#
# WHAT THIS FLOOR ASSUMES, and how to tell the assumption is gone. A floor is a REPLACEMENT rate
# only while it is small against the park it maintains, and the same pair of numbers is not small
# against every park: 5 factories are about 1 % a month of a 5000-plane fighter park and several
# times that of the 150-plane scout park or the 200-plane transport park (scout_cap /
# transport_cap, common/script_constants/wa_ai_production.txt). A maintained line keeps producing
# while the park stays above its cap and neither support role takes attrition, so both drift well
# past their bar: at the deep floor, +380 scouts and +652 transports over three years, i.e. 3.5x
# and 4.3x their cap. That is an accepted cost, not an oversight.
# The fact is gone when a support park reads far above its cap in a save; the fix is 1 flat for
# scout and transport, not a change to the six combat roles.
#
# The carrier roles are NOT here: their volume lever is the deck-derived ladder of
# WA_AI_PRODUCTION_DEFAULT_cv_plane.txt behind the saturation brake, and that ladder now survives
# a cap closure by itself (should_keep_cv_*_type).

WA_AI_PRODUCTION_air_maintenance_floor_fighter = {
	enable = { WA_AI_PRODUCTION_should_maintain_fighter_type = yes }
	abort_when_not_enabled = yes

	ai_strategy = { type = equipment_production_min_factories id = fighter								value = 1 }
}
