# WHAT THIS FILE OWNS (Phase 7e, 2026-08-16)
# The coalition-level air policy of the Axis in the West: what every Axis air force is told to avoid
# while the western front is not open, while the Battle of Britain is not on, and where in France no
# front exists. It replaces the faction-shaped half of the legacy GER.txt air family:
#
#   battle_of_france_no        -> WA_AI_MILITARY_AXIS_AIR_western_front_not_open
#   battle_of_france_yes (the -1M half on 20 / 290 / 11)
#                              -> WA_AI_MILITARY_AXIS_AIR_avoid_unfronted_france (11 dropped, see below)
#   battle_of_britain_no       -> WA_AI_MILITARY_AXIS_AIR_avoid_british_isles
#
# The German-only half (the Reich air-defence pull, id-keyed on German regions) is
# WA_AI_MILITARY_COUNTRY_GER_AIR.txt; the +100k schwerpunkt half of battle_of_france_yes was not carried
# over (see that file's header: the +50k contested pull composed with the -40k unfronted suppression
# already yields the north/south differential).
#
# What changed and why (AGENTS.md principles 1 and 2):
# - Gating: the seven-tag list (GER/ITA/ROM/HUN/BUL/FIN/SPR) and `tag = GER OR is_in_faction_with = GER`
#   become WA_AI_MILITARY_is_axis_member. `date < 1940.5.1` / `date > 1940.11.1`, `has_war_with = FRA`,
#   `has_war_with = SOV`, `has_capitulated` become state: an enemy holds the Channel coast and our side
#   holds nothing in Western Europe (front not open); our side holds the coast, an enemy holds London
#   and we are not fighting the Comintern (Battle of Britain window); our side holds no state of a
#   French region (no front there). Switches: common/scripted_triggers/WA_AI_MILITARY_triggers.txt,
#   section "AIR - Axis western front / Battle of Britain / Reich air defence".
# - Values: the legacy -500,000 / -1,000,000 join the SUPPRESSION RETUNE tiers (-500k -> -20k,
#   -1M -> -40k): mild avoidance that a contested theatre (+50k, WA_AI_MILITARY_DEFAULT_AIR_theatres.txt)
#   or the engine's own combat terms override. At the legacy values these blocks were black holes:
#   battle_of_france_yes's -1M on 11 Southern Norway was live during Weseruebung and cancelled the
#   Scandinavia theatre pull outright, and battle_of_britain_no's -1M on the Channel/North Sea regions
#   was live from Barbarossa to the end of the war.
# - Dropped: 11 Southern Norway from the France block - Norway is the Scandinavia air theatre's
#   business (WA_AI_MILITARY_DEFAULT_AIR_scandinavia), and a France-offensive block writing Norway was
#   the bug above, not a design.
#
# Every block also reads WA_AI_MILITARY_AIR_actor_enabled (the WA_TEST_air_actors kill switch, always
# true outside the harness), like the DEFAULT and ALLIES air files.
#
# What this family cannot do: strategic_air_importance ranks regions for the planes the engine already
# requests; it does not create demand (checklist R15 RECUT 2026-08-16). Suppressions here bias planes
# AWAY from regions where nothing of ours fights; they cannot make a Luftwaffe appear over Britain.
############################################################################################################


# purpose: keep Axis air out of French airspace while an enemy holds the Channel coast and our side holds
#          nothing in Western Europe - the Phoney War, or any Franco-Axis war whose front has not opened
# range:   -20000 per strategic region (was -500000)
# policy:  Additive per region
# domain:  AIR
WA_AI_MILITARY_AXIS_AIR_western_front_not_open = {
	enable = {
		WA_AI_MILITARY_is_axis_member = yes
		WA_AI_MILITARY_AIR_actor_enabled = yes
		WA_AI_MILITARY_AIR_channel_coast_enemy_held = yes
		NOT = { WA_AI_MILITARY_AIR_theatre_contested_western_europe = yes }
		# a member whose capital sits in France is defending its homeland, not avoiding it
		NOT = { capital_scope = { OR = { region = 239 region = 19 region = 290 region = 20 region = 5 } } }
	}
	abort_when_not_enabled = yes

	ai_strategy = { type = strategic_air_importance id = 19 value = -20000 }	# Central France
	ai_strategy = { type = strategic_air_importance id = 239 value = -20000 }	# Northern France
	ai_strategy = { type = strategic_air_importance id = 20 value = -20000 }	# Southern France
	ai_strategy = { type = strategic_air_importance id = 290 value = -20000 }	# Western France
}
