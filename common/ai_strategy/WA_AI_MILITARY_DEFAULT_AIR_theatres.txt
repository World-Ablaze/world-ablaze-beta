############################################################################################################
# WA AI Military V2 - DEFAULT_AIR theatres
############################################################################################################
# Canonical domain: AIR (strategic_air_importance, land-theatre-facing).
# Sea-facing strategic_air_importance rules stay in WA_AI_NAVAL_* files; see
# documentation/WA_AI_MILITARY_SYSTEM.md section 3 and WA_AI_MILITARY_TYPES_REFERENCE.md.
#
# WHY THIS FILE EXISTS
# The engine distributes air wings across strategic regions by importance = engine terms
# (own combats x100, own armies x25; a stocked main front in active combat scores ~35,000)
# PLUS scripted strategic_air_importance. This mod's replace_path removed vanilla's
# Europe/theatre push guidance and, before this file, the only scripted pulls were a handful
# of country/faction specials (ENG.txt D-Day/Husky, GER/ITA/SOV blocks, NAVAL downfall/sealion).
# Result observed in campaign 66d6b53c: the USAAF kept 8,595 of 13,791 planes in the
# continental US through 1944 - no generic rule ever asked any country to base air where its
# side was actually fighting.
#
# DESIGN
# One block per air theatre (a bounded list of strategic regions). A block enables when the
# theatre is CONTESTED for the country - an enemy controls land there AND the country's side
# (itself, an ally, a subject or a co-belligerent) controls land there - detection lives in
# WA_AI_MILITARY_AIR_theatre_contested_* (common/scripted_triggers/WA_AI_MILITARY_triggers.txt).
# Purely dynamic-state gating: works identically for any country, any faction line-up,
# historical or ahistorical. Countries whose CAPITAL sits inside the theatre are excluded -
# defending the homeland is already the engine's job (combats/armies terms), and the exclusion
# prevents pile-on-at-home overstacking (the RAF pattern).
#
# A scripted weekly-emission architecture (the AIFC armor meta_effect pattern) was rejected:
# strategic_air_importance is region-id-keyed, and no WA_AI_MAP_* generated data provides a
# state-to-strategic-region lookup, so a scripted variant would need new generated map data
# for no added expressiveness - the theatre list below is bounded and declarative.
#
# VALUE ECONOMY (+10,000 per region)
# ~30% of a hot main front (~35,000): wins against idle rear regions (armies-only terms are a
# few thousand), loses to any active home front, and is well below the existing emergency
# family (+100k..+500k D-Day/Husky/sealion pushes) and the suppression family (-250k..-1M
# ENG/GER negatives) - this file can never out-shout either. Matches the +10k standing pulls
# already in WA_AI_NAVAL_COUNTRY_ENG/ITA (North Africa emphasis).
#
# KNOWN LIMITS
# - A pull toward a theatre where the country's side holds no in-range air-base capacity is
#   inert (the engine only rebases into friendly capacity). Acceptable: the pull activates the
#   moment basing appears. Air-base CONSTRUCTION on active fronts is a separate follow-up in
#   the construction system, deliberately out of scope here.
# - Japan Home Islands (154) is deliberately absent: WA_AI_NAVAL_FACTION_ALLIES_downfall_push
#   and JAP_anti_bombing already own that region's air economy.
# - China's interior regions are deliberately absent: every likely participant fights there
#   with its capital/armies in-theatre (engine terms dominate), and JAP country blocks already
#   tune that air war.
# - Burma (189) / Thailand (340) carry a -50,000 suppression for western Allies at war with
#   Germany from ENG.txt Allies_dont_bomb_random_places; for those countries the +10k here is
#   intentionally dominated until that block aborts.
############################################################################################################

# purpose: base air power forward into the North Africa / Mediterranean coast theatre while it is contested by our side and an enemy
# range:   +10000 per strategic region (engine main-front reference ~35000)
# policy:  Additive per region
# domain:  AIR
WA_AI_MILITARY_DEFAULT_AIR_north_africa = {
	enable = {
		has_war = yes
		surrender_progress < 0.1
		# skip token air forces (WA air scale is ~1/3 vanilla)
		has_deployed_air_force_size = { size > 99 }
		# home defence is the engine's job - no extra pull onto your own capital theatre
		NOT = { capital_scope = { OR = { region = 182 region = 126 region = 329 region = 215 region = 328 region = 128 } } }
		WA_AI_MILITARY_AIR_theatre_contested_north_africa = yes
	}
	abort_when_not_enabled = yes

	ai_strategy = { type = strategic_air_importance id = 182 value = 10000 } # Morocco
	ai_strategy = { type = strategic_air_importance id = 126 value = 10000 } # Algeria
	ai_strategy = { type = strategic_air_importance id = 329 value = 10000 } # Tunisia
	ai_strategy = { type = strategic_air_importance id = 215 value = 10000 } # Libya
	ai_strategy = { type = strategic_air_importance id = 328 value = 10000 } # Cyrenaica
	ai_strategy = { type = strategic_air_importance id = 128 value = 10000 } # Egypt
}
