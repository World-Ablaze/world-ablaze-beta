#          withholds the boosts above - engine default assignment still routes a total-commitment
#          released army onto the only live European fronts (owner report 2026-08-27: RAJ divisions
#          in BEL/HOL mid-battle of France).
# range:   -100 (E2 floor, full veto)
# policy:  Additive per area; escape hatch (WA_AI_MILITARY_ECONOMY.md 2.4): the audience trigger
#          excludes every European-capital member AND every member of the bulwark's own bloc, so
#          the veto can never reach a homeland defender - including a colonial subject standing on
#          its own ground, which the colonial leg below would otherwise cover; a dead, capitulated,
#          fallen or out-of-faction bulwark opens the gate and this brake stands down with it. On
#          non-historical difficulty the gate is always open, so the brake never arms there.
# domain:  FRONT

# purpose: make Allied fronts facing Germany actually execute their attack orders when the weekly
#          posture calculus says battles are winnable. The old gate here (alliance_strength_ratio > 2)
#          compared WORLDWIDE faction strength and never fired in a late war with a full-strength Axis,
#          leaving the Allies passive in France with crushing local superiority. Posture level 1 uses
#          fighting_army_strength_ratio, which counts only engaged armies. Equipment and manpower
#          floors live inside the calculus (WA_AI_MILITARY_posture_effects.txt).
#          FIX 54 (2026-08-13, campaign 02bd4445): the target is no longer the literal tag GER.
#          The posture calculus publishes a verdict PER enemy, but this block could only ever read
#          one of them, so anything held by a German puppet was invisible to it - state 29
#          Nord-Pas-de-Calais is owned AND controlled by RBE, and 17/28/32 in eastern France were
#          never taken in 21 monthly samples while 138 Allied divisions stood in France. The literal
#          `tag = GER` is replaced by a country_trigger that reads the per-enemy verdict, which
#          covers RBE/RCZ/RBL/VIC and every ahistorical enemy for free, and removes the need for any
#          region list. `has_war_with = GER` goes with it - the stale-variable note below is now
#          handled by the country_trigger's own has_war_with = ROOT term.
#          WIDENING, stated deliberately: an Allied member now also executes against non-German
#          enemies where the posture says the battles are winnable (ENG vs JAP in Burma, say), which
#          the tag-scoped version never did. That is the intended generic behaviour, but it IS new.
#          The name is kept for this step only; [offensive-posture] stage 2 collapses these three faction pairs
#          into one Default-layer pair, at which point the block disappears.
# range:   n/a (front_control)
# policy:  Exclusive per front - priority 300; mutually exclusive with the grind block below by
#          posture level; outranked by the level-500/10000 emergency stops in DEFAULT_FRONT_control.
# domain:  FRONT
WA_AI_MILITARY_ALLIES_exec_vs_germany = {
	enable = {
		WA_AI_CONFIG_is_in_allies = yes
		WA_AI_MILITARY_posture_has_execute_target = yes
	}
	abort_when_not_enabled = yes

	ai_strategy = {
		type = front_control
		country_trigger = {
			has_war_with = ROOT
			has_capitulated = no
			OR = {
				# Too small for a posture verdict - the calculus never publishes one for a
				# non-major on <= 4 states, which is precisely the German puppet population.
				# See WA_AI_MILITARY_posture_has_execute_target for the full argument.
				AND = {
					is_major = no
					NOT = { num_of_controlled_states > 4 }
				}
				ROOT = { check_variable = { WA_AI_MILITARY_posture_vs_@PREV = 1 } }
			}
		}
		ratio = 0.2
		priority = 300
		ordertype = front
		execution_type = balanced
		execute_order = yes
	}
}

#          No "too small" branch here on purpose: an enemy with no published verdict reads 0, never
#          2, so exec and grind stay mutually exclusive exactly as before.
# range:   n/a (front_control)
# policy:  Exclusive per front - priority 300; mutually exclusive with the exec block above by
