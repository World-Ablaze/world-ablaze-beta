# ============================================================================
# [maintenance-floor] MAINTENANCE FLOORS - land equipment, DEFAULT tier.
# ============================================================================
# The factory floor that keeps a fielded park supplied, and therefore modernising, when nothing
# else does. One pair of blocks per equipment ARCHETYPE; the gates, the two reasons a park goes
# unsupplied and the support-equipment Schmitt pair are all in
# common/scripted_triggers/WA_AI_PRODUCTION_maintenance_triggers.txt.
#
# `_archetype`, never the TYPE. An engine type is shared: `armor` is all 36 tank chassis, so a
# floor on it cannot tell a light park from a modern one; `anti_tank` is towed AT plus the four
# tank destroyers, `artillery` every gun plus the five SPG chassis, `anti_air` towed AA plus the
# five SPAA (MEASURED, the `type =` blocks of common/units/equipment/). A type floor would be
# satisfied by tracked production while the towed park stayed empty. Expert AI 5.0 reaches the same
# conclusion in a larger sample: 115 of its 116 floors are `_archetype`, one is a type (`train`).
#
# `enable` / `abort` rather than `abort_when_not_enabled`: the two blocks read DIFFERENT bars, so
# the support floors arm on a real shortage and are held until stock genuinely recovers. The armour
# floors instead remain active while their chassis class is fielded.
#
# [armor-variant-maintenance] EVERY tank archetype carries the floor, not only the four main gun
# classes: a Flakpanzer is `light_spaa_tank_chassis` and a Sturmpanzer `light_assault_tank_chassis`,
# so the light_tank_chassis floor never reached either and those lines ran on perceived need alone.
# Each floor is self-limiting - its gate reads `num_target_equipment_in_armies_k@<arch>`, which is 0
# for a chassis this country's templates never ask for, so an unfielded archetype costs nothing.
# WHAT THIS COSTS: the floors SUM across archetypes. A country fielding six armour archetypes has
# 30 factories reserved before any other production is weighed, against a `wartime_min_mils` gate of
# only 20. Gone wrong when the harness totals line reads a factory sum near the country's mils.
#
# The values are the one place `constant:` cannot be used (`ai_strategy value =` takes a literal).
# Source of truth: wa_ai_production.maintenance.floor_base for every chassis and
# .ground_floor_base / .ground_floor_deep_add for the support guns - keep these literals equal.
#
# WHAT THESE FLOORS ASSUME, and how to tell each fact is gone.
# (1) `equipment_production_min_factories_archetype` forces allocation on an archetype whose
#     perceived need is ~0 - the engine doc says it "forces" but also that it ignores how many
#     factories are available, and that sentence is about the POOL, not about need. Gone when a
#     country the harness reads as maintained shows 0 factories on that archetype.
# (2) The line runs the NEWEST producible variant (the AI walks the `parent` chain), i.e. the floor
#     modernises rather than merely producing. Gone when a maintained park keeps receiving its
#     oldest variant.
# Both are ASSUMED and owed an owner console reading - `event wa_maint.3 <TAG>`, then the
# production panel.
# ============================================================================
