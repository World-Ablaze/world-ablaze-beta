# [med-axis-posture] (2026-08-17). Region layer: geography-driven home defence of the Italian peninsula for
# WHOEVER is "an Italy" - gate is WA_AI_MILITARY_is_italian_homeland_power (owns AND cores mainland
# soil), so the same rules serve fascist ITA, the co-belligerent ITA after ita_armor.897 (same tag),
# the released RSI (RIT) and a civil-war dynamic Italy, without a single `tag =`.
#
# Why this file exists (campaign 0edbc955, Oct-Dec 1943): the whole Italian army was in Libya /
# Sudan / Kenya, 0-3 divisions on the peninsula, and the Allies walked from Sicily to the Alps with
# 7-12 divisions. The only home-defence content was a put_unit_buffers block gated on a DATE, and no
# rule at all pulled a front to Italian soil once an enemy stood on it. Every gate here is a
# controller/owner question that flips both ways as ground is lost and retaken (design principle 1).
#
# Three tiers, each additive on the previous:
#   floor      - any war: a light island / mainland garrison so the peninsula is never empty
#   threatened - an enemy holds owned belt ground (Sardinia, Corsica, Dodecanese, Zadar, Albania,
#                Istria, Primorska), or a foreign army occupies Tunisia, or the mainland is invaded
#   invaded    - an enemy stands on cored mainland / Sicilian soil (FRONT twin pulls the front)
# Ratios per block are E4-legal (<= 0.25); summed per state group with the AXIS guard
# (WA_AI_MILITARY_FACTION_AXIS_THEATRE.txt) they read: Sicily/south 0.10 + 0.20 (+ ally 0.06/0.12),
# mainland anchors 0.15 + 0.10 (+ ally 0.06/0.12), Sardinia 0.05, Corsica 0.03 ([med-axis-posture]).
# Anchors = all 15 states (mainland + Sicily): after the Fall Achse transfer the co-belligerent ITA may own
# nothing north of Naples, and it must still be an Italy here.
# Every buffer has its own order_id (floor 9601-9603 + 9615, threatened 9604-9605 - separate orders, so the
# tiers stack whatever the engine does with two blocks on one order_id) and
# subtract_fronts_from_need = no - see `# pool:`.
# Canonical domain: THEATRE. See documentation/WA_AI_MILITARY_TYPES_REFERENCE.md.
############################################################################################################
