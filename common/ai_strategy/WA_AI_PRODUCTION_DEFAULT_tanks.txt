# ============================================================================
# Tank Equipment Production Strategies
# ============================================================================
# These strategies are used to control the production of tank equipment.
# All strategies use triggers from WA_AI_PRODUCTION_tanks.txt
# No country tags should appear in this file.
#
# Main strategy types used:
# - equipment_production_min_factories_archetype: minimum factories for archetype
# - equipment_variant_production_factor: production factor for specific variant
#
# [armor-prod-category] PARITY RULE: every specialised variant of a class (TD, assault gun, SPAA,
# SPG, infantry support) carries the SAME factor as its chassis, and a class focus applies to the
# whole class: light 45, medium 150, heavy 60, modern 90, focus +50 / +75 / +75. Literals on
# purpose - `@` in an ai_strategy payload is unverified (no vanilla or Expert AI file uses it) and
# `constant:` is not resolved there (wa-constants-registry). The engine's need is already
# proportional to the template (150 medium chassis against 12 SPAA per division); a smaller factor
# on a variant distorts that ratio a second time. Assumes the factor scales the engine's perceived
# need (documentation.info); ASSUMED a variant no template needs multiplies zero and costs nothing.
#
# [modern-switch-amorce] NAMED EXCEPTION to the class column above, and the rule of record for it:
# the MAIN GUN weight follows the chassis the PARK FIELDS, not the class name. medium main sits at
# 150 until the modern window opens, goes NEGATIVE while the country primes its modern line, and
# sits at the legacy 45 once the switch is taken; modern main is
# 150 from the latch. Modern VARIANTS stay at 90 on purpose - only the 4 line battalions change
# chassis, the same target still wants 6 medium_support_armor_battalion_line, so the variants are
# complements of a medium division, not of a modern one. Do NOT restore modern main to 90 in a
# parity audit: the 150 is the medium class weight following its own role.
# ============================================================================
