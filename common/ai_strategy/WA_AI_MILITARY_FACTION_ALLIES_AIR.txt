# WHAT THIS FILE OWNS
# The Allied strategic bombing campaign against the Reich: how hard the western coalition is told
# to stay away from German air space, and when that avoidance is released. It replaces three
# legacy ENG.txt blocks, relocated here as Faction-layer content (Phase 7c):
#
#   ENG_FRA_allies_avoid_bombing_GER        -> WA_AI_MILITARY_ALLIES_AIR_reich_blackout
#   Allies_bombing_germany_is_too_costly    -> WA_AI_MILITARY_ALLIES_AIR_reich_raid_too_costly
#   allies_avoid_bombing_austria_prussia    -> WA_AI_MILITARY_ALLIES_AIR_reich_deep_out_of_reach
#
# THE LADDER
# Every switch is a deployed-strategic-bomber count, coalition-wide. All four thresholds and both
# ring definitions live in common/scripted_triggers/WA_AI_MILITARY_triggers.txt (section "AIR -
# Allied Reich bombing ladder"); tune the campaign there, never by editing the values below.
# The legacy blocks decided the same question with dates (a blackout until 1941.10.1, a
# suppression until a 1944.2.1 hard backstop) plus a USA-only tech gate - assumptions that hold
# only on the historical path. Capability gating gives the same historical shape while still
# producing sane play when the Allies arm early, arm late, or never arm at all.
#
# Rungs are additive and deliberately overlap, so the net walks down one step at a time. Each
# rung enables below its own bar and aborts above the NEXT bar, which gives free hysteresis: a
# fleet oscillating around a threshold does not flip the campaign on and off week to week.
#
#   coalition strat bombers |  near ring (6/7/8/296)  |  deep ring (294/38)
#   ------------------------+-------------------------+---------------------
#   0   - 450               |  -60,000                |  -80,000
#   451 - 700               |  -40,000 +50,000 = +10k |  -60,000
#   701 - 900               |        0 +50,000 = +50k |  -20,000 +50,000 = +30k
#   901 +                   |        0 +50,000 = +50k |        0 +50,000 = +50k
#
# THE HANDOVER ([commonwealth-handoff])
# The three suppression rungs only ever LIFT avoidance. Until [commonwealth-handoff] nothing then pulled the
# bomber arm ONTO the Reich: with every rung aborted the net was exactly 0 and the engine's own
# front-following terms picked the targets. Campaign 5078fe10 is the proof - the ladder released
# fully between 1943.12 and 1944.4 and never re-armed, and in the 22 months that followed the RAF
# flew every strategic-bombing sortie over France, Italy and the Balkans, not one over a German
# region, while German factory levels rose 453 -> 602 and no German state carried
# last_strategic_bombing before November 1945. WA_AI_MILITARY_ALLIES_AIR_reich_raid_pull and
# _reich_deep_raid_pull are the missing positive half: each turns ON at the same bar its matching
# suppression turns OFF at, which is why the middle rows of the table above now net positive.
# The pull is additionally gated on ROOT's OWN bomber count (@WA_AI_AIR_BOMBER_OWN_ARM) because
# strategic_air_importance moves EVERY mission in a region - a fighter-only air force handed the
# pull would send its fighters to Germany instead of to its own front.
#
# The deep ring lags the near ring by one rung. That is the old B-17 range gate
# (allies_avoid_bombing_austria_prussia, which keyed on a USA tech the AI never researched in
# time and therefore carried a hardcoded 1944.2.1 backstop) restated as capability: a coalition
# fielding 700+ heavy bombers has the generation that reaches Vienna; one fielding 350 does not.
#
# VALUE ECONOMY
# The contract set by the ENG.txt suppression retune holds: the deepest contested-theatre pull is
# +50,000 per region (WA_AI_MILITARY_DEFAULT_AIR_theatres.txt) and the engine's hot-main-front
# reference is ~35,000. A -60,000 net therefore keeps the region off the target list against
# standing pulls while staying far below the emergency family (+100k Husky / +200k D-Day), which
# must keep precedence. The legacy -500,000 and -1,000,000 values these blocks carried were black
# holes in the sense of WA_AI_MILITARY_ECONOMY.md principle 2: nothing in the ledger could ever
# out-vote them, so every other air signal over Europe was unreadable.
#
# LEDGER - other writers on these regions:
# - WA_AI_MILITARY_DEFAULT_AIR_theatres.txt has NO Germany block by design (the capital-theatre
#   exclusion, and the engine's own combat/army terms, already cover the Reich once fronts reach
#   it). The rings below are therefore the only standing scripted weight on 6/7/8/294/38.
# - WA_AI_MILITARY_ALLIES_AIR_avoid_occupied_europe (Phase 7d, this file) adds -8,000 on 296 (Poland)
#   while the Channel coast is entirely enemy-held; WA_AI_MILITARY_ALLIES_AIR_avoid_out_of_theatre
#   adds -40,000 on 22 (Czechoslovakia). Their target sets are occupied-ally and out-of-theatre,
#   not the Reich.
# - WA_AI_MILITARY_ALLIES_AIR_home_islands_lost pushes +20,000 on 6/8/38 and +200,000 on 294 once the
#   British home islands are lost. Under the legacy -500,000 blackout that push was arithmetically
#   dead; against the -60,000/-80,000 here it wins, which is what that block always intended.
# - THE ONE THING NONE OF THESE VALUES DO: create demand. strategic_air_importance ranks regions for
#   the planes the engine already requests; see the Phase 7d banner further down and checklist R15.
# - WA_AI_MILITARY_COUNTRY_ENG_THEATRE.txt WA_AI_MILITARY_ENG_strategic_bombing_focus_THEATRE and
#   its USA twin in WA_AI_MILITARY_COUNTRY_USA_THEATRE.txt write area_priority (+4000 on
#   germany/prussia/austria). area_priority is an ARMY theatre-distribution type - it is listed
#   with front_control / garrison / put_unit_buffers in common/ai_strategy/documentation.info and
#   air mission target selection never reads it. Those two blocks were the intended positive half
#   and they have been writing to the wrong axis; they are left alone because they are correct as
#   army-weighting blocks, and the actual air-side positive half is the raid pull below.

# range:   -20000 per strategic region (engine main-front reference ~35000)

	allowed = {
		WA_AI_CONFIG_MILITARY_is_western_allies_major = yes
	}
	enable = {
		WA_AI_MILITARY_AIR_actor_enabled = yes
		WA_AI_CONFIG_is_in_allies = yes
		WA_AI_MILITARY_AIR_enemy_holds_germany = yes
		NOT = { WA_AI_MILITARY_AIR_allies_bombers_reach_nucleus = yes }
	}
	abort = {
		OR = {
			NOT = { WA_AI_MILITARY_AIR_actor_enabled = yes }
			WA_AI_MILITARY_AIR_allies_bombers_reach_raid_force = yes
			WA_AI_MILITARY_AIR_theatre_contested_germany = yes
			NOT = { WA_AI_MILITARY_AIR_enemy_holds_germany = yes }
		}
	}

	ai_strategy = { type = strategic_air_importance id = 7 value = -20000 }		# Western Germany

############################################################################################################
# A small Allied air force stays over its own soil (2026-08-18)
############################################################################################################
# An Allies member fielding 399 aircraft or fewer keeps its whole air force on its own national
# territory: every foreign air theatre this mod pulls toward is suppressed for it, and the one theatre
# containing its own capital is left alone.
#
# WHY. strategic_air_importance RANKS regions and the engine fills them in that order with the planes
# it requests (see the WHY THIS FILE EXISTS banner of WA_AI_MILITARY_DEFAULT_AIR_theatres.txt). A
# coalition minor is ranked by exactly the same +50,000 contested-theatre pull and +100k/+200k
# emergency pushes as the RAF and the USAAF, so its 200 planes go to the head of a foreign queue and
# its own airspace gets whatever is left - which, for a small force, is nothing. A major with thousands
# of planes can afford that; a minor cannot. The bar is the whole rule.
#
# WHY THE COALITION WANTS THIS, not just the minor. A forward theatre has a FINITE amount of friendly
# air-base capacity, and in WA it is half of vanilla's: NDefines.NBuildings.AIRBASE_CAPACITY_MULT is
# 100 per airbase level here against vanilla's 200 (common/defines/05_defines.lua), and overcrowding a
# base is penalised on top of that (NDefines.NAir.CAPACITY_PENALTY = 2). Every plane a coalition minor
# parks on a Mediterranean or Channel field is capacity the RAF and the USAAF cannot use - and their
# aircraft are the better ones, built on deeper research and upgraded designs, so the same slot is
# worth more in their hands. Sending the minors home is how the front gets cleared for the machines
# that actually win the air war; keeping their obsolete airframes out of the queue is the point, not a
# side effect. (MEASURED: the two defines and the finite-capacity rule - see the KNOWN LIMITS banner of
# WA_AI_MILITARY_DEFAULT_AIR_theatres.txt, "the engine only rebases into friendly capacity". ASSUMED:
# that a minor's wings actually displace a major's in a given region - nothing in a savegame has been
# read to confirm the contention, only that the capacity it competes for is bounded.)
#
# WHAT IS SUPPRESSED. The ten air theatres of WA_AI_MILITARY_DEFAULT_AIR_theatres.txt, plus the two
# region groups this file's own pushes target: the British Isles (home_islands_invasion_threat +200k)
# and the Reich ring (the raid pull +50k). East Africa is deliberately absent - no scripted air pull
# points there, so suppressing it would create a black hole with nothing to cancel.
#
# WHY NO ARCHETYPE GATE IN allowed. The rest of the suppression family carries
# WA_AI_CONFIG_MILITARY_is_western_allies_air_power so that a continental member is never told to avoid
# its own homeland. Here the per-block capital-region exclusion does that job generically, for any
# member, on any map - and gating on the eight-tag western-allies archetype would exclude precisely the
# minors this family exists for.
#
# WHY -300,000, when Phase 7d retired the -500k black holes. That retune was about avoidance applied to
# the WHOLE coalition, where a net-negative ledger made every pull inert everywhere. This one applies
# only to countries with nothing to spare, and each of them keeps one non-suppressed theatre by
# construction. The value has to dominate or it does nothing: the largest stack a member can see on a
# suppressed region is +250,000 (this file's t3 row - the Channel push +200k composed with the
# contested western-Europe pull +50k). -300,000 nets -50,000 there and out-shouts every other pull.
#
# LEDGER for a 250-plane Allied minor whose capital is outside Western Europe, on region 239:
#   t0  no landing, no staging:                 no_foothold -20k + home_only -300k        = -320k
#   t1  an overseas ally stages, push arms:     +200k - 300k                              = -100k
#   t2  theatre contested, DEFAULT pull adds:   +200k + 50k - 300k                        =  -50k
#   t3  the minor rebuilds past 500 planes:     home_only releases, ledger returns to +250k
#   t4  it attrites back under 400:             home_only re-arms (band: arm 399, release 499)
#
# WHAT THIS CANNOT DO. The same limit as every block in this file: it decides WHERE requested planes
# go, it does not create demand. A minor whose own divisions are fighting abroad still generates engine
# demand there, and this family now ranks that region below its homeland - that is the intended trade,
# and the one case where the rule costs something.
############################################################################################################
