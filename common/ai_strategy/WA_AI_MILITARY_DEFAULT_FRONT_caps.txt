# [minor-expeditionary-fitness]
# purpose: a country that cannot equip a real infantry division does not hold a front outside its own
#          neighbourhood - no militia expeditionary corps in someone else's theatre
# range:   -100 (E2: the type is a percent factor, -100 is the full veto, lower is saturation)
# policy:  Additive with the other caps in this file - every one of them brakes, none pulls
# domain:  FRONT
# escape hatch (WA_AI_MILITARY_ECONOMY.md section 2.4): built into the state_trigger. Own, core and
#          adjacent states are excluded by the predicate, so the veto can never starve the country's
#          own defence - it only ever removes fronts that are somebody else's.
# residual: CLOSED 2026-08-25 the way this line said to. The Faction pulls that reached an unfit member
#          (ALLIES europe_first +150/+75, east_africa_contested +150) now carry
#          WA_AI_MILITARY_is_fit_for_expeditionary_front in their own enable, so the brake is no longer
#          netted against them. The value stays -100: E2 makes it the full veto and anything lower is
#          saturation, linted by tools/military_economy_audit.py. Watch for a NEW pull appearing on an
#          area an unfit minor can reach - the fix is that block's enable, never this value.
# unlike the three caps above, this one does NOT exempt Allies members: the case it exists for is
#          precisely a badly equipped minor being pulled onto a faction's overseas front.
WA_AI_MILITARY_CAPS_unfit_army_stays_home = {
	enable = {
		WA_AI_MILITARY_should_caps_unfit_army_stays_home = yes
	}

	ai_strategy = {
		type = front_unit_request
		state_trigger = { WA_AI_MILITARY_state_is_beyond_home_reach = yes }
		value = -100
	}
}
