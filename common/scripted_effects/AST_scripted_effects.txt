# Composition mirrors WA_AI_TEMPLATES_GENERIC_HEAVY_INFANTRY_30_MIX_MOT
# (common/ai_templates/WA_AI_TEMPLATES_infantry.txt, flag value 1006) so the
# player and the AI field the same division from this focus tree.
#
# Must be called immediately before any create_unit that spawns it: the AI
# renames and reshapes its own templates at will, so no pre-existing template
# name can be relied on when the country is AI-controlled.
#
# The maintenance company is dropped when tech_maintenance_company is missing.
# That technology must never become a focus prerequisite: its AI research weight
# is zeroed unless WA_AI_CONFIG_DIVISIONS_use_armored_divisions or
# _use_mechanized_divisions is true for the country, so a focus gated on it
# could become permanently unreachable for the AI. Degrading the template here
# keeps the focus reachable whatever the AI has researched. Every other sub-unit
# below is either active by default or enabled by a technology whose
# WA_AI_RESEARCH_needs_* trigger is always = yes.
