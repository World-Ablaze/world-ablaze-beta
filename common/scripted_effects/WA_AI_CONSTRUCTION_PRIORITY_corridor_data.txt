#	Contract (temp arrays, cleared here, consumed within the same corridor pass):
#	  corridor_node_prov_   province id of the node, in corridor order (direction is meaningless -
#	                        the corridor is SYMMETRIC: whoever holds two consecutive nodes builds the
#	                        rail between them, so ENG from Egypt, an Ally in Tunisia after Torch, and
#	                        ITA / GER holding Libya all use the same list)
#	  corridor_node_depot_  1 = a supply hub (supply_node) is wanted at this node if none exists
#	  corridor_node_port_   1 = a naval base is wanted at this node if none exists
#
#	Rules for a node list:
#	  - list only the provinces where a DECISION lives (a depot/port attribute, or a junction the
#	    pathfinder must be forced through); the pathfinder (type 2, no partial) finds the intermediate
#	    provinces, so Bardia / Sollum / Gazala need no entry;
#	  - a node with depot_ = 1 must be a province where supply_node is buildable (any land province);
#	    a node with port_ = 1 must be coastal (naval_base is only_costal);
#	  - no tag, no date, no side: gating is control + war state, computed by the engine.
############################################################################################################
