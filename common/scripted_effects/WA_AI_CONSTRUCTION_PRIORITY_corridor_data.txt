############################################################################################################
#	World Ablaze AI mod - Priority Construction - THEATRE CORRIDOR DATA ([na-corridor])
#
#	Pure data: each effect below fills the corridor node arrays and nothing else. The engine that
#	consumes them is WA_AI_PC_railway_corridor_pass (railway_core) via
#	WA_AI_PC_railway_STRATEGY_theatre_corridor (railway_strategies). Read the doc section
#	"Theatre corridors" in documentation/WA_AI_RAILWAY_SYSTEM.md before adding a corridor.
#
#	Contract (temp arrays, cleared here, consumed within the same corridor pass):
#	  corridor_node_prov_   province id of the node, in corridor order (direction is meaningless -
#	                        the corridor is SYMMETRIC: whoever holds two consecutive nodes builds the
#	                        rail between them, so ENG from Egypt, an Ally in Tunisia after Torch, and
#	                        ITA / GER holding Libya all use the same list)
#	  corridor_node_depot_  1 = a supply hub (supply_node) is wanted at this node if none exists
#	  corridor_node_port_   1 = a naval base is wanted at this node if none exists
#	  corridor_node_fwdport_ 1 = a FORWARD port is wanted here, but only for the ATTACKER: the node is
#	                        ours, its province is OWNED by an enemy of ROOT (we stand on conquered soil),
#	                        one neighbouring node is enemy-held (the front is right there) and the other
#	                        neighbouring node is ours (the rear is secured). A defender on its own soil
#	                        never gets it - a supply port behind a static defensive line is wasted civs.
#
#	Rules for a node list:
#	  - list only the provinces where a DECISION lives (a depot/port attribute, or a junction the
#	    pathfinder must be forced through); the pathfinder (type 2, no partial) finds the intermediate
#	    provinces, so Bardia / Sollum / Gazala need no entry;
#	  - a node with depot_ = 1 must be a province where supply_node is buildable (any land province);
#	    a node with port_ = 1 must be coastal (naval_base is only_costal);
#	  - no tag, no date, no side: gating is control + war state, computed by the engine.
############################################################################################################

# [levant-iraq] The Jordan approach to Iraq - Ma'an 7151 -> Amman 4017 -> Ruwaished 4440, the
# Jordanian border province with Iraq. Purpose: while the holder of Jordan is at war with the
# Iraqi power, put a supply hub on the last friendly province before the Iraqi border and connect
# it to the rail the Levant already has. Owner order 2026-09-01; the gate is
# WA_AI_PC_corridor_theatre_live_levant_iraq (WA_AI_CONSTRUCTION_triggers.txt) and it closes on
# the Iraqi power's capitulation.
#
# Map facts (2026-09-01, map/railways.txt + map/supply_nodes.txt + the generated province graph):
# ALL THREE NODES ARE IN STATE 455 (Jordan), and so is every province the pathfinder can put
# between them - 7151-10089-4017 and 4017-4591-4574-1544-4440. That is load-bearing: PC admission
# is scoped to the state of a segment's FIRST province, so every segment of this corridor is
# scoped to one state with one controller and the pathfinder/admission mismatch that forced the
# 13481 junction into the North Africa list cannot arise here.
#   7151  supply node, railed L1 to 4017 via 10089 (map/railways.txt:1095) - the anchor on the
#         existing Levant network; Palestine reaches it over 4111-1074-7170-7151 and 7170-7176.
#   4017  supply node, railed L1 - forced junction, so the hop to 4440 leaves from the Jordanian
#         railhead instead of a route the sizer would have to pay for twice.
#   4440  land / arid (map/definition.csv:4441), NO supply node and NO railway at start; its only
#         Jordanian neighbour is 1544. Neighbours 13831 / 13832 are state 675 (Iraq) - this is the
#         border province, which is why the depot goes here and not one province back.
# No port node: the corridor is entirely inland.
# No node inside Iraq, deliberately - the owner asked for a depot on 4440 fed from the Levant, not
# for rail laid into Iraq. The war band therefore cannot come from an enemy-held node and is
# declared here instead (_corridor_war_band_ = 1).
