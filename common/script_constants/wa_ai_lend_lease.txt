#	Land-row keys, all read against the FREE stockpile (`num_equipment@<archetype>`):
#	  donor_floor  the donor never goes below this; also the "has an exportable surplus" bar
#	  starve       a recipient at war below this is starving of that archetype
#	  base         tier-1 amount per weekly pull
#	  tier2/tier4  donor stock above which the pull is x2 / x4 base (never below donor_floor)
#	infantry / support rows are the pre-Fix-92 values (35k/10k/6k, 6k/4k/1.2k) unchanged; the
#	other rows are first calibrations - see documentation/WA_AI_LEND_LEASE_RELIEF_DESIGN.md.
#	Waste bound: the amount is clamped to (starve + base - recipient stock), so an archetype the
#	recipient does not field accumulates at most `starve + base` units, once, then the pull stops
#	- the reason no "does it consume this" gate exists (design §3).
#	The convoy row documents its separate scale-aware keys in place. The archetype index (idx)
#	is the WA_TLM_llr_sent_n^idx position - keep it stable; the TLM
#	arrays are sized 11 (idx 0 unused) in WA_TLM_core.txt - grow them if another row is added.
####################################################################################################
