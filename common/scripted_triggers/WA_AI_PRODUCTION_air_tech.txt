# Air-production TECH vocabulary of the AI. Read only by WA_AI_PRODUCTION_air.txt and by
# WA_aircraft_production_strategies; layer 2 (OBSERVATION), so it answers "what is true", never
# "should we act".
#
# Naming: every gate a `should_build_*` decision reads is `has_worthwhile_<line>` - one per
# production line, no exception, so a decision never carries tech data of its own. The remaining
# `has_*_tech` triggers are not line gates: the jet ones are vetoes read by the effect, and
# has_late_cv_naval_bomber picks between two force caps.
#
# Every has_worthwhile_* lists at least one rung of EVERY tech tree that owns the family. A missing
# tree does not narrow the line to the others, it bars that nation outright - who may build is
# decided by the archetypes in WA_AI_CONFIG, never by a hole in a tech list.
#
# Why these are WA_AI_ and not the plain WA_has_*_tech of WA_triggers.txt: a `has_worthwhile_*`
# trigger carries the AI's own judgement - the tree whose early models it refuses to spend a
# factory on. That judgement must never gate player-facing content, and the name is what stops a
# later author from wiring it there.
#
# [ai-owns-its-tech-list] This file reads NOTHING from WA_triggers.txt. Where the same list also
# exists there for player content (fighter, heavy fighter, tactical bomber, all read by
# HUN_scripted_triggers.txt), the copy below is deliberate: the player asks "does this country hold
# the tech", the AI asks "may it spend a factory on this". The two agree today and are free to
# diverge, so a retune here must never be able to move player content. Do not collapse a copy back
# into a call to the generic trigger.

# whose start_year is 1940 or later, on the base line and on the ad-tech line separately. Earlier
# rungs are pre-war models no factory should go to. The rule reproduces the three picks this repo
# already had (ENG 1940, FRA 1940, JAP 1940), which is why it is the rule and not a taste.
# Every tree that owns the family is listed: leaving one out silently bars that nation from the
# line, whatever the archetype says. A country holds only its own tree's techs, so the flat OR
# selects itself; who may actually build is the archetype's job, not this trigger's.
