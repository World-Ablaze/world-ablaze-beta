############################################################################################################
#	USA PACIFIC HOARD - console harness for [usa-pacific-hoard] (the Pacific garrison share cap).
#
#	Effects: common/scripted_effects/WA_TEST_usa_pacific_hoard.txt
#
#	CONSOLE:
#	    tag USA      (the report runs in the scope of the country under test)
#	    event wa_uph.1
#	  Then read logs/game.log and search for "USA PACIFIC HOARD TEST".
#
#	WHAT GOOD LOOKS LIKE. On a 1944.6+ save with the USA at war with Germany and Japan and over 75
#	divisions: facts latched=1, indep size-over-bar=1 pacific-risk=1 enemy-in-europe=1, ship
#	two_ocean_large_army=1, gate full=0 capped=1 low_army=0. On a 1942 save under 75 divisions:
#	latched=0 and the shipped line reads full=1 capped=0. `full` and `capped` reading 1 together on
#	any save is the defect this harness exists to catch. The latch is set by the MONTHLY on_action:
#	on a fork the flag can lag one month behind size-over-bar - that is cadence, not a fault.
#
#	Own file, own namespace on purpose (wa-testing SKILL, harness contract v1): a report fired from
#	events/wa_events_test.txt once read every country-valued trigger false.
############################################################################################################

	id = wa_uph.1
	hidden = yes
	is_triggered_only = yes
