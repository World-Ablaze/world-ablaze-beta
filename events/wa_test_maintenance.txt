#	RECIPE
#	------
#	Do NOT tag into the country under test - tag-switching makes it human and is_ai reads no.
#	From any tag (observer included):
#
#		event wa_maint.1 GER    one country report: ten archetype rows + the verdict
#		event wa_maint.2        the same report for every AI country with a fielded army
#		event wa_maint.3 GER    the FIELD PROBE: prints the gates and the free spares, then tells you
#		                        what to read in the production panel. Fire it, wait a month, fire it
#		                        again - the spares of a maintained archetype must GROW.
#
#	Output: logs/game.log under "MAINTENANCE TEST". Read the `scope :` line FIRST - anything but
#	1 1 1 1 0 means STOP (see the effect header). Then the VERDICT line: all five values must read 1.
#
#	HOW TO READ A ROW. `require` is what this country armies ask for, in thousands; `spares` is the
#	free stockpile; `ratio` is spares over require. For SUPPORT rows, the floor arms under the arm bar
#	and is released over the release bar. For CHASSIS rows, fielded demand alone holds a flat floor of
#	5 factories. A row with require = 0 owes no floor, and that is not a fault.
#
#	TWO REASONS A ROW CAN BE MAINTAINED: the four CHASSIS rows follow fielded demand regardless of
#	stock or expansion demand; the six SUPPORT rows follow a shortage. Amtrac also carries a closure
#	term because peace closes its line.
#
#	WHAT TO FIRE IT ON
#	------------------
#		any AI major at war       every fielded main chassis class should read floor 5; the support
#		                          rows show which guns are below their reserve bars
#		GER after CZE annexation light remains floor 5 even with the captured light-tank stock;
#		                          medium also reads 5 once medium divisions are fielded
#		USA or JAP at peace       the amtrac case: build_amphibious_mech carries has_war, so peace
#		                          closes the line and takes its 3/8/15 floors with it while the
#		                          marine divisions keep their amtracs
#		any country with no tanks every chassis row is 0; this is the fielded-demand control
#
#	Effects: common/scripted_effects/WA_TEST_maintenance.txt.
#	Design: documentation/WA_AI_MAINTENANCE_FLOOR_PROPOSAL.md. Marker: [maintenance-floor].
############################################################################################################
