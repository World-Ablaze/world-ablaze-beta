#	RECIPE
#	------
#	Do NOT tag into the country under test - tag-switching makes it human and is_ai reads no.
#	From any tag (observer included):
#
#		event wa_airb.1 GER     one country's air-line report (swap the tag at will)
#		event wa_airb.2         the same report for every AI major
#		event wa_airb.3 GER     run the SHIPPED 2-day pulse once, then report - use this on a LOADED
#		                        save: the purge books are written by the pulse only, so a fresh load
#		                        reads every book 0 until the next pulse. Expected, not a failure.
#		event wa_airb.4 GER     run the pulse AND the monthly air-budget reconcile, then report - the
#		                        budget books are monthly, so this is the one to fire on a loaded save
#		                        when the `budget: books` line reads 0.
#		event wa_airb.5 SOV     cap probe: does `has_deployed_air_force_size size < constant:` read the
#		                        bar - fire on a country whose naval-bomber park is far above 2000.
#
#	Output: logs/game.log under "AIR LINES TEST". Read the `scope :` line FIRST - anything but
#	1 1 1 1 0 means STOP (see the effect header). Then the VERDICT line: all four values must read 1.
#
#	WHAT TO FIRE IT ON
#	------------------
#		GER 1939-1941      fighter+multirole, cas, attacker, fast/strike/tactical, naval open together
#		ENG 1940.7-1940.11 the Battle of Britain programme: bomber and carrier lines must read 0
#		USA after 1942     cv_fighter open, cv_cas 0 (no carrier strike power is named), land cas 0
#		any minor          own_air_arm=0 -> every patron-gated line 0 (the control)
#
#	Effects: common/scripted_effects/WA_TEST_air_budget.txt. Owning subject: WORK.md [air-budget].
