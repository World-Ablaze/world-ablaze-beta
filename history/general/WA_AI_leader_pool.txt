# [recruit-loop] Character-template pool for scripted AI leader recruitment.
#
# What this protects: a leader created by generate_character keeps a reference to its token in the
# savegame, and on load the engine resolves that token against a registry built by PARSING script
# files - not by executing them. A token that exists only in the text a meta_effect expands at
# runtime is unresolvable, and the leader loses its template and its portrait on every reload.
#
# The fact this assumes: a generate_character block in a parsed history/general file registers its
# token even when the surrounding effect never runs. Same site vanilla uses for its generic
# advisors (history/general/generic_advisors.txt, WA's own copy - the folder is replace_path'd).
# How to tell that fact is gone: "Character template WA_AI_gen_* does not exist anymore" in
# logs/error.log when loading a save.
#
# limit = { always = no } - declaration only. Nothing is created at game start.
# The last index here is constant:wa_ai_leaders.pool.last_index, which the recruit gates in
# WA_AI_leader_recruitment_effects.txt compare against; tools/check_constants.py holds the pair equal.
#
# Do not hand-edit a single entry: each role block must stay identical to the matching runtime call
# in WA_AI_leader_recruitment_effects.txt, portrait category included (army for land commanders,
# navy for admirals - the category the engine writes into the save).
