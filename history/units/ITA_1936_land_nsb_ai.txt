####### Division Templates #######
#
# AI-ONLY ORDER OF BATTLE. Loaded instead of ITA_1936_land_nsb.txt when
# has_dlc = "No Step Back" and is_ai = yes (see history/countries/ITA - Italy.txt).
# Mirrors the SOV_1936_land_nsb / SOV_1936_land_nsb_ai split.
#
# It exists for exactly one reason: "Divisione di Fanteria" is buffed here so the AI
# template designer assigns it the infantry role instead of "Camicie Nere".
#
# The engine keeps ONE division template per role and decommissions the rest during its
# first template pass (around 1936.1.5-1.7). A decommissioned template can never be
# recruited, so its division count is frozen for the rest of the campaign. The role goes
# to whichever template scores highest against the role's ENABLED target, scoring
# (matched units - per-category oversize) / total target units.
#
# WHICH TARGET MATTERS: none of the flag-gated targets in WA_infantry_role are enabled
# until WA_AI_TEMPLATES_has_infantry_focus_completed fires - for Italy that is the hidden
# infantry_modernization_tech set by ITA_infantry_modernization, which the AI does not reach
# for well over a year (the [templates-admission] deadline latch cannot fire before mid-1939
# either). Until
# then WA_INFANTRY_TEMPLATE is unset and the only enabled infantry target in the game is
# WA_AI_TEMPLATES_GENERIC_INFANTRY_FALLBACK (15x heavy infantry, 3 pack artillery + 3
# anti-tank regimental, 9 support companies). The templates are decommissioned in the
# first week of 1936, so THE FALLBACK IS THE TARGET THAT DECIDES. Tune against it.
#
#                              vs FALLBACK   vs 1004 (after the focus fires)
#     Camicie Nere                 0.6000       0.6000
#     Divisione di Fanteria        0.2333       0.3333   <- player OOB, loses, decommissioned
#     Divisione di Fanteria        0.6667       0.7667   <- this file, wins both
#
# Camicie Nere carries division_cap = ITA_militias_cap (12), so when it held the infantry
# role Italian infantry was capped at 12 divisions for the whole pre-war period. SOV had
# the same end state via a different route - see the warning in
# common/ai_templates/WA_AI_TEMPLATES_garrison.txt.
#
# The changes below are all-heavy line battalions, a 6th regimental support, and two extra
# support companies. Keep the two files in sync for everything EXCEPT this template; the
# divergence is deliberate and documented here.
#
# Not done in the shared OOB because it rewrites a historical Italian division, which
# should not change for human players.
